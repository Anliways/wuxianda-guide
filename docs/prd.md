# 需求文档

## 1. 应用概述

### 1.1 应用名称
无限大游戏攻略站

### 1.2 应用描述
为《无限大》游戏玩家提供全面攻略信息的Web站点,涵盖剧情通关、彩蛋收集、资料查询、改装搭配等核心内容,帮助玩家快速获取游戏攻略与数据信息。

## 2. 用户与使用场景

### 2.1 目标用户
- 《无限大》游戏玩家
- 需要查询攻略、数据、配置方案的用户
- 寻找彩蛋、礼包码等隐藏内容的用户

### 2.2 核心使用场景
- 玩家在游戏过程中遇到关卡难题,查询通关攻略
- 玩家需要了解角色、武器、怪物等详细数据
- 玩家寻找地图隐藏彩蛋位置与触发条件
- 玩家获取当前有效礼包兑换码
- 玩家查询武器改装、角色搭配的最优方案
- 新手玩家学习游戏基础操作与快速上手

## 3. 页面结构与功能说明

### 3.1 全局布局规则

#### 3.1.1 PC端布局
- 采用顶部导航栏布局
- 顶部导航栏包含:站点名称「无限大游戏攻略站」、全局搜索入口、功能模块导航、明暗主题切换按钮
- 功能模块导航采用下拉菜单形式,按功能分组展示:
  - 攻略指南分组:剧情攻略、场景彩蛋、新手攻略、活动攻略
  - 游戏资料分组:资料库Wiki(下设角色、武器、载具、怪物、Boss子分类)
  - 方案推荐分组:改装方案、搭配方案、家园搭配方案
  - 其他分组:礼包码
- 鼠标悬浮导航项时,下拉菜单平滑展开,菜单项清晰易扫描
- 明暗主题切换按钮位于导航栏右侧,点击可在亮色/暗色模式间切换
- 主内容区域为全宽展示,充分利用屏幕宽度
- 导航栏保持固定位置,滚动时不随内容移动
- 视觉层级清晰,当前所在模块需高亮显示

#### 3.1.2 移动端布局
- 采用汉堡菜单交互方式
- 顶部展示站点名称、汉堡菜单图标、明暗主题切换按钮
- 点击汉堡菜单图标展开侧边抽屉,显示功能模块导航(按分组展示)
- 主内容区域全宽展示

#### 3.1.3 面包屑导航规则
- 所有详情页顶部展示面包屑导航
- 面包屑导航清晰展示当前页面在信息架构中的位置路径
- 支持点击面包屑中的任意层级返回对应页面
- 适用页面:章节/关卡详情页、彩蛋详情页、角色详情页、武器详情页、载具详情页、怪物详情页、Boss详情页、活动详情页、改装方案详情页、搭配方案详情页、家园搭配方案详情页

### 3.3 功能说明

#### 3.3.1 首页
- 顶部导航栏展示站点名称「无限大游戏攻略站」、全局搜索入口、功能模块导航(下拉菜单形式)、明暗主题切换按钮
- 全局搜索入口支持搜索攻略、资料、方案等内容
- 主内容区域展示热门攻略推荐或最新更新内容

#### 3.3.2 剧情攻略页
- 按章节/关卡分类展示攻略列表
- 每个攻略条目显示:章节/关卡名称、难度标识、更新时间
- 支持按章节筛选
- 点击进入章节/关卡详情页

#### 3.3.3 章节/关卡详情页
- 顶部展示面包屑导航(如:首页 / 剧情攻略 / 第一章)
- 展示章节/关卡名称
- 提供通关路线说明
- 提供剧情解读内容

#### 3.3.4 场景彩蛋页
- 按地图分类展示彩蛋列表
- 每个彩蛋条目显示:彩蛋名称、所在地图、奖励类型
- 支持按地图筛选
- 点击进入彩蛋详情页

#### 3.3.5 彩蛋详情页
- 顶部展示面包屑导航(如:首页 / 场景彩蛋 / 星辰之森彩蛋)
- 展示彩蛋名称与所在地图

- 点击条目进入对应详情页

- 属性雷达图:可视化展示角色多维属性(如攻击、防御、生命、速度等)
- 技能列表:展示技能名称、技能图标、技能说明

#### 3.3.8 武器详情页

## 4. 业务规则与逻辑

### 4.1 导航交互规则
- PC端顶部导航栏固定位置,页面滚动时保持可见
- 当前所在模块在导航栏中高亮显示
- 鼠标悬浮导航项时,下拉菜单平滑展开,移开鼠标后菜单收起
- 下拉菜单支持多级分类,资料库Wiki下设角色、武器、载具、怪物、Boss子分类
- 移动端汉堡菜单点击后展开侧边抽屉,再次点击或点击内容区域关闭抽屉
- 导航切换时页面内容平滑过渡

### 4.2 面包屑导航规则
- 面包屑导航展示完整路径层级,各层级间使用分隔符(如/)分隔
- 面包屑中的每个层级均可点击,点击后跳转至对应页面
- 当前页面在面包屑中不可点击,仅作展示
- 面包屑路径示例:
  - 章节详情页:首页 / 剧情攻略 / 第一章
  - 角色详情页:首页 / 资料库Wiki / 角色 / 黎星
  - 改装方案详情页:首页 / 改装方案 / 星陨步枪暴击流

### 4.3 主题切换规则
- 用户首次访问时,默认使用亮色模式
- 用户点击主题切换按钮后,页面立即切换至对应主题模式
- 主题切换状态保存至本地存储
- 用户刷新页面或再次访问时,自动加载上次选择的主题模式

### 4.4 搜索规则
- 搜索范围覆盖所有攻略、资料、方案内容
- 搜索结果按相关度排序
- 搜索结果展示:标题、所属分类、内容摘要

### 4.5 筛选规则
- 资料库Wiki支持多条件组合筛选
- 筛选条件包括但不限于:稀有度、属性类型、等级范围
- 筛选结果实时更新

### 4.6 内容更新规则
- 活动攻略需实时更新当前进行中的活动
- 礼包码需标识过期状态,过期礼包码不删除但需明确标注
- 攻略与方案内容需显示最后更新时间

### 4.7 数据展示规则
- 数值型数据需统一单位与格式
- 时间信息需明确展示年月日时分
- 图标与图片需清晰展示,支持点击放大查看

### 4.8 详情页布局规则
- 角色、武器、Boss详情页采用上下分栏布局
- 顶栏展示主要信息(名称、分类、稀有度/等级、简介)
- 底栏展示详细内容(属性雷达图、技能列表、攻略建议等)
- 布局需适配竖屏与横屏显示,确保数据清晰展现

### 4.9 属性雷达图规则
- 雷达图展示多维属性(如攻击、防御、生命、速度等)
- 雷达图各维度数值需与详细属性数据保持一致
- 雷达图需清晰标注各维度名称与数值

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 搜索无结果 | 提示「未找到相关内容」,建议调整搜索关键词 |
| 筛选无结果 | 提示「暂无符合条件的内容」,建议调整筛选条件 |
| 活动已结束 | 在活动攻略页标识「已结束」,不再展示在进行中列表 |
| 礼包码已过期 | 在礼包码页标识「已过期」,显示过期时间 |
| 图片加载失败 | 显示占位图或文字说明 |
| 详情页内容缺失 | 显示「内容待补充」提示 |
| 技能图标缺失 | 显示默认占位图标 |
| 属性雷达图数据不完整 | 仅展示已有维度数据,缺失维度不显示 |
| 导航栏在小屏幕设备显示不全 | 移动端自动切换为汉堡菜单模式 |
| 面包屑路径过长 | 中间层级使用省略号缩略,鼠标悬浮显示完整路径 |
| 主题切换失败 | 保持当前主题模式,提示用户稍后重试 |

## 6. 验收标准

1. 用户访问首页,在顶部导航栏看到站点名称、搜索框、功能模块导航(下拉菜单形式)、明暗主题切换按钮
2. 用户鼠标悬浮「攻略指南」导航项,下拉菜单平滑展开,显示剧情攻略、场景彩蛋、新手攻略、活动攻略四个子项
3. 用户鼠标悬浮「游戏资料」导航项,下拉菜单展开,显示资料库Wiki及其下设的角色、武器、载具、怪物、Boss子分类
4. 用户点击下拉菜单中的「角色」,进入资料库Wiki角色列表页
5. 用户在角色列表中点击某个角色,进入角色详情页,顶部看到面包屑导航(如:首页 / 资料库Wiki / 角色 / 黎星)
6. 用户点击面包屑导航中的「资料库Wiki」,返回资料库Wiki页
7. 用户点击导航栏右侧的明暗主题切换按钮,页面立即切换至暗色模式
8. 用户刷新页面,页面保持暗色模式
9. 用户再次点击主题切换按钮,页面切换回亮色模式
10. 用户通过下拉菜单进入「搭配方案」页,点击某个搭配方案,进入详情页,顶部看到面包屑导航(如:首页 / 搭配方案 / 黎星速攻流)
11. 用户点击面包屑导航中的「首页」,返回首页
